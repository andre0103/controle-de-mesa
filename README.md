# Controle de Mesa

App para bares de sinuca. Criado por @luigi.

- **Snooker:** cobrança por tempo (valor da hora editável e salvo).
- **Sinuca pequena:** cobrança por ficha (valor da ficha editável e salvo, quantidade digitada).

## Como obter o APK

1. Envie esta pasta para um repositório no GitHub (branch `main`).
2. Abra a aba **Actions** > **Gerar APK**. Ele roda sozinho a cada envio.
3. Ao terminar (uns 5 a 8 minutos), abra a execução e baixe **controle-de-mesa-apk** em *Artifacts*.
4. Descompacte o zip e instale o `controle-de-mesa.apk` no celular.

### APK na aba Releases (link fixo de download)

```
git tag v1.0.0
git push origin v1.0.0
```

O APK aparece em **Releases** do repositório.

## Alterar o app
Edite `www/index.html` e envie ao GitHub. Um novo APK é gerado automaticamente.
